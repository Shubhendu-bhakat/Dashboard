# Project Setup & Run Guide

Follow these steps to run the project locally or build it for production.
s1 . Clone the Repository

```bash
git clone <Repo name>
cd <FOLDER_NAME>
Using npm
npm run dev

Using yarn
yarn dev

Using bun
bun run dev


The app will be available at:

http://localhost:3000

Build for Production

This creates an optimized, production-ready build.

Using npm
npm run build

Using yarn
yarn build

Using bun
bun run build
